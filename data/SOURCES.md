# Data provenance

The primary card transaction stream is generated by this repository. Its tokens and identities are fictitious; no PAN, bank account, or customer record is used.

The public benchmark is [OpenML dataset 43627](https://www.openml.org/search?id=43627&type=data), an anonymized two-day credit-card fraud dataset originally attributed to the Machine Learning Group at Université Libre de Bruxelles. Its [OpenML API metadata](https://www.openml.org/api/v1/json/data/43627) lists the license as “Database: Open Database, Contents: Database Contents,” 284,807 rows, 492 fraud labels, and a public Parquet URL. `Time` is seconds from the first transaction; `V1`–`V28` are anonymized PCA components; `Amount` and `Class` are the other fields. We download it locally to `data/raw/openml_43627.parquet`, which is ignored by git. The data is **not** redistributed in this repository. The public benchmark is evaluated separately from the synthetic feature model because it does not contain card/device/merchant IDs or the same online feature contract.

The locally cached Parquet file measured SHA-256 `91650a62cb263b7fd76610a8f2fa55c4e861033b56dd51ed22d707838c95e0cf` on 20 October 2026. The original download command was not preserved, so this hash identifies this local copy rather than proving its complete acquisition history. Do not claim model transfer from synthetic to public data; the feature spaces differ.
